# 手機房間版面驗證（2026-11-03）

## 範圍與視覺

線上等待房間、對戰電腦設定房間。保留森林綠、奶油紙色、棕色描邊及動物角色；以區塊間距、完整寬度的主要操作、獨立設定區降低手機版的擁擠感。

- 房名與房號分列，狀態可換行。
- 開始／準備操作移到房間上方；保留伺服器決定的開局條件。
- 手機空席雙欄、已入座玩家獨占一列；長暱稱、身分標記可換行，AI 難度選單獨占卡片下一列，避免英文單字被擠到斷行。
- 角色選擇與規則可收合，收合仍顯示摘要。設定保存在既有 store／伺服器，不因收合遺失。
- 電腦難度改為有間距的二乘二選項；個別對手設定各自成卡，不與角色名稱擠在一列。
- 房間互動目標至少 48px；沿用自訂 ScrollArea、Select、Segmented 等元件。Select 的可見標籤透過 aria-labelledby 關聯。
- 桌機保留多欄；線上房間聊天獨立成欄。手機聊天高度固定，長訊息可在自訂捲動區閱讀。

## 測試環境與矩陣

Windows、Node 22.23.2、Microsoft Edge headless、SwiftShader。專案宣告的正式 Node 版本為 26.12.1，本次沒有更動版本設定；未在 Node 26 或實體手機執行。

- `node e2e/matrix.mjs`：三語系、五種既有尺寸全部通過。含首頁、設定、說明、挑戰、電腦設定、遊戲、暫停及適用尺寸的資訊欄。

- `node e2e/flow.mjs`：通過。完成電腦對局、結算、再開一局、暫停重開、返回、單人挑戰、連續重開及觀戰切換。

房間專用回歸指令（需先 build，並啟動 preview 4173 與 server 3130）：

```powershell
$env:APP_URL = 'http://127.0.0.1:4173/'
$env:SHOTS = '1'
Set-Location client
node e2e/room-layout.mjs
```

也可在 `client/` 執行 `node e2e/room-layout.mjs`，並已納入 `npm run e2e`。測試包含鍵盤展開收合、暱稱及規則保留、七名電腦、八個滿席、AI 選單、聊天長訊息、邀請視窗、離開房間，以及單機不連後端。調整房間人數後先等待伺服器快照再點下一次，避免測試輸入競態。

## 已知限制

既有 `online.mjs` 未整套通過：手機觀戰檢查要求 `.hud-chip.pick` 至少兩名，但既有 `game.jsx` 的窄版使用 `chipList(hud, 1)`，觀戰者僅呈現一名其他玩家。後續尋找其他頂部玩家／觀看提示會逾時。本次未修改對戰 HUD 或放寬既有驗證。該次執行已通過連線、重連、玩家與觀戰邀請、聊天、準備與開始；多人結算後的瀏覽器操作未由此套件完成驗證，房間／結算及生命週期另有 server 測試通過。

未額外宣稱完整 `npm run e2e`、真機鍵盤、完整觸控手勢、紀錄清除／遷移或所有聲音設定已逐項實測。
