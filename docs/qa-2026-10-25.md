## 已執行

- `npm --prefix Backend~ test`：原有規則 25 項、房間 30 項及真實 WebSocket 檢查通過。未更動權威規則或房間行為。
- `node Backend~/tests/web-bridge.js`：新增的 CSS 寬度橋接測試通過，已納入 npm test。
- `node CoreTests~/golden.js` 產生無 BOM UTF-8 golden，再執行 `dotnet run --project CoreTests~/CoreTests.csproj -- CoreTests~/golden.json`：20 項通過。
- Golden 依既有規則允許至少 500 tick 後 AI 路徑分歧：本次 versus4、versus8、versus3-boost 分別先比對 2041、633、1228 tick；並非全局逐 tick 完全一致。沒有 snap.json，C# 線上快照樣本比對略過。
- `dotnet run --project GameCheck~/InputTests/InputTests.csproj`：多指、釋放、移出、冪等重置、輸入清理與規則停止加速，以及六尺寸 1×／2× DPI 計算通過。
- `dotnet build GameCheck~/GameCheck.csproj -p:DefineConstants=UNITY_WEBGL`：條件編譯簽名檢查通過；修補替身缺少的既有 WebGLInput 簽名。仍有四個既有未使用欄位警告。
- `git diff --check`：通過。

初次新增測試時補齊替身的 PointerEventData 建構函式；一次同時建置相同輸出目錄造成檔案鎖，改為循序後通過。上述都是測試環境問題，未當成遊戲缺陷。
