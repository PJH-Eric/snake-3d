# 改寫驗收記錄：Unity → React + Three.js + Node.js

日期：2026-10-27。前端、後端與規則核心全面改回 Web 技術；Unity 專案檔案已在測試完成後刪除。

## 架構

| 層 | 內容 |
| --- | --- |
| `shared/` | `rules.js`（確定性規則）、`ai.js`（四段電腦難度）、`locales.json`（繁中／英文，433 個 key）；前後端共用，改成 ESM |
| `server/` | Node.js 權威房間伺服器（零第三方套件）：房間、席位、觀戰、邀請 token、聊天、權威對局；移除 `/api/presence` |
| `client/` | Vite + React 18 + Three.js：3D 舞台、自訂元件組、單機與線上畫面、WebAudio 合成音效 |

## 巡檢中發現並修復

| 問題 | 修正 |
| --- | --- |
| 自訂捲動區的 viewport 高度未被容器限制，短螢幕上彈窗與頁面內容被裁掉、捲軸不出現 | `.sa` 改 flex 容器，viewport `flex: 1 1 auto; min-height: 0`；版面檢查新增「捲動區未被限制高度」 |
| 捲軸軌道在無內容溢出時被 `display:none`，之後永遠量不到尺寸 | 改用 `visibility: hidden` |
| 窄版抽屜資訊欄蓋住右上角設定／語言按鈕 | 抽屜寬度最多 `100vw - 140px`；檢查加入資訊欄與右上角重疊 |
| 窄版 HUD 分數列與小地圖重疊 | 窄版小地圖固定在右側、HUD 分數列保留右側空間，只顯示自己與前幾名 |
| 3D 場景曝光過亮、名牌過大 | 調整環境光／平行光強度與名牌尺寸 |
| 側欄操作說明把語系片段拼成不通順的句子 | 改用完整句 `set.keys` |
| 頁面直接使用原生按鈕（角色挑選、語言切換） | 新增 `RadioCard`，語言切換改 `IconButton text` |
| e2e：邀請連結產生後競態、語言偏好被測試腳本覆寫 | 等待連結數量增加；初始化腳本只在未設定時寫入語言 |

## 已知限制與假設

- 驗證使用 Microsoft Edge + SwiftShader 軟體繪製 WebGL；未在實體 iOS／Android 裝置、Safari 或 Firefox 驗證，實體觸控手感與效能需實機確認。
- 美術與音效為程式產生的暫用資產；可替換成正式資源。字型由 Google Fonts 載入，離線時退回系統字型。
- 「回到房間」在單機模式以「回到設定」呈現（單機沒有房間）；線上為「回到房間」。
- 沒有 push、建立雲端服務或設定網域；`.github/workflows/pages.yml` 與 `render.yaml` 已就緒，需使用者授權後才會被平台使用。
- Render 免費層會休眠與冷啟動；房間只存在記憶體。
