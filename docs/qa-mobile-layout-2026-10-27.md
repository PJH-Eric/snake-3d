# 手機版面優化

## 重現與改善

以正式建置、Edge + SwiftShader、320×568 CSS px、長暱稱測試確認原版問題：

- 搖桿與加速鈕的固定尺寸互相重疊，推到底的搖桿旋鈕也會碰到加速鈕。
- HUD 高 204px，長暱稱換行擠壓遊戲區。
- 設定音量標籤與滑桿各占一列，操作選項高度小於 48px。

修改後：

- 手機底部搖桿 140px、加速鈕 116px，短橫向改為 112px／100px；保留 16–26px 邊距並加入左右、底部安全區。旋鈕行程依實際圓盤大小限制，不再伸入另一側控制。
- 手機只保留自己與領先者的分數，自己的姓名改為「你」標示；長姓名以省略顯示，完整文字及名單保留在資訊欄。挑戰模式的分數、長度、等級仍完整呈現。
- 320px HUD 降為 82px；390px 與測試橫向 HUD 為 40px。短橫向小地圖改為 72px，手機直向 84px。
- 鏡頭避讓區依 HUD 實際高度與底部控制占用空間計算，處理字體載入、換行與尺寸變動；ResizeObserver 在離開／重開場次時解除。
- 手機設定視窗減少邊距、音量標籤與滑桿同列，選項與關閉鈕至少 48px，固定頁首／頁尾並保留自訂捲軸。
